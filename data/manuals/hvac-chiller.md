# Air-Cooled Chiller — Service Manual (Model AC-220)

## Section 2.3 Fault code table
Code E01 indicates low refrigerant pressure. Code E02 indicates high
condenser pressure, usually from a fouled coil or a failed condenser fan.
Code E05 indicates a flow switch trip on the evaporator circuit. Code E11 is a
compressor overload trip and locks the unit out until it is manually reset at
the panel.

## Section 3.4 Filter service
Filters FLT-C22 are changed every 2000 running hours or quarterly, whichever
comes first. A blocked filter raises the approach temperature and is the most
common cause of a gradual loss of cooling capacity.

## Section 5.2 Condenser coil cleaning
Clean the coil with a low-pressure water spray from the inside outward.
Pressure above 40 bar bends the fins and permanently reduces capacity. Use a
fin comb on any bent section afterwards.
